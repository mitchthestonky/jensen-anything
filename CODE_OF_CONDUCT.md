# Code of Conduct

This project makes fun of a financial narrative. It does not make fun of people.

Be kind and assume good faith. Harassment, personal attacks, discrimination and publishing someone's
private information are not welcome here, and neither is using this tool to mislead anyone about a
real company.

Maintainers may edit or remove contributions and block participants who break these rules. To report
a problem, use the private contact options on the repository owner's GitHub profile.
