# Security

`jensen-anything` reads two local files and writes to one output directory. It makes no network calls
and runs none of its input.

Please report vulnerabilities privately through GitHub's "Report a vulnerability" option on the
Security tab, if it is enabled, or through the contact options on the owner's GitHub profile. Do not
open a public issue for an unfixed vulnerability.

Only the latest commit on `main` is supported. Falsely reassuring valuations are a feature, not a
vulnerability.
